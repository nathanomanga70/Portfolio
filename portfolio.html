FlyRank — General AI Fluency Intern

Since July 2026, I have worked as a General AI Fluency Intern at FlyRank, applying AI tools to real aviation dispatch tasks under a structured weekly assignment series. The work is deliberately hands-on: each assignment produces a working artifact, not a slide about AI — a prompt ladder tested against a real GO/NO-GO decision, an automation pipeline that runs on real FAA/EASA sources, an MCP-connected tool tested on real files.

Representative work from the internship includes:

  • A six-version prompt iteration ladder for an operational weather briefing (LFPG crosswind/convection GO-NO-GO analysis), documenting exactly why each added constraint improved or degraded the output — including a version that failed and was kept as evidence.
  • A four-stage automation workflow ("Weekly Aviation Dispatch Brief") built in a Claude Project, tested against five real FAA regulatory and operational sources, with documented time savings and named failure points.
  • A working MCP connector setup (Google Drive), demonstrated on three tasks a plain chat interface could not perform — including reading a full project file directly from cloud storage.

Sub-project — AI-Powered NOTAM / METAR / TAF Briefing Assistant

The internship's capstone project: an AI assistant (built on Claude) that takes raw NOTAM and METAR/TAF text and produces a structured, severity-tiered operational brief — decoding ICAO abbreviations into plain language and classifying each item as Critical, Moderate, or Informational. The system prompt enforces one non-negotiable rule, drawn directly from aviation safety culture: flag uncertainty rather than guess.
